## 📌 About the Project

This project focuses on replicating and improving a **Reinforcement Learning (RL)-based Feature Selection** framework using Q-learning and Temporal Difference (TD) learning. The implementation explores feature selection techniques across the Australian Credit Approval, WPBC, and Sonar datasets.

## 🛠️ Tech Stack

| Category | Technologies |
|---|---|
| Language | Python |
| Data Processing | NumPy, Pandas |
| Machine Learning | Scikit-learn, SVM |
| Visualization | Matplotlib, Seaborn |
| Environment | Jupyter Notebook |
| Algorithms | Q-Learning, TD(0), ε-Greedy |

## ⚙️ Work Implemented

- 🔹 Replicated the existing RL-based feature selection methodology.
- 🔹 Implemented state-value learning and Average of Reward (AOR).
- 🔹 Applied ε-greedy exploration and exploitation.
- 🔹 Compared RL-based feature rankings with traditional feature selection methods.
- 🔹 Developed an improved Q-learning approach with a **STOP action** and feature-count penalty.
- 🔹 Incorporated fold-specific preprocessing and held-out test evaluation.
- 🔹 Studied feature reduction and classification performance across datasets.

## 📂 Datasets

- **Australian Credit Approval**
- **Wisconsin Prognostic Breast Cancer (WPBC)**
- **Sonar**
